# Atlas Navigator downloads

[Download Atlas customer updater](https://github.com/mahmoud0al-haddad/atlas-navigator-downloads/releases/download/v3.0.0/Atlas-Updates.exe)

The Windows customer app checks signed navigation customization updates and downloads selected compatible offline maps from their official source. No GitHub account is needed.

**Supported device:** the verified SiRF Windows CE navigator profile, 480 × 272, TFAT FAT32 storage of 3,789,553,664 bytes, with the existing supported MapFactor Navigator 26 installation. Other hardware is not yet validated.

Stable: **3.0**. Optional preview: **3.0.1 TEST**, selected with the TEST checkbox. Preview releases never replace the stable feed automatically.

Public packages contain Atlas customization files and patches for an existing installation. They do not include the original navigation engine, firmware, maps, favourites, routes or account credentials. MapFactor Navigator and OpenStreetMap notices remain in the device software.

## العربية

حمّل برنامج تحديث أطلس، وصّل جهاز الملاحة، ثم افحص تحديث البرنامج. لتجربة المعاينة فعّل خيار TEST. اختر الخرائط المطلوبة من القائمة لتنزيلها أو تحديثها.

نسخة TEST تغيّر صورة بداية الملاحة ورسالة السلامة فقط. احتفظ بالطاقة أثناء النقل. فحص التنزيل والتوقيع لا يُعد اختبار قيادة أو ضماناً لتغطية الطرق والكاميرات.
