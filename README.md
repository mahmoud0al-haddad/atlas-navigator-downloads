## العربية

برنامج العميل لتنزيل الخرائط الأوفلاين وتحديثها، وفحص تحديث برنامج الملاحة وتثبيته. لا يحتاج حساب GitHub، ولا يحتوي أدوات التجهيز أو التنظيف.

ثبّت البرنامج، وصّل جهاز الملاحة، ثم اختر الخرائط المطلوبة أو افحص تحديث البرنامج. التحديثات موقّعة، ويُحفظ أصل الملفات المتغيرة قبل استبدالها. لا يُعاد تثبيت المحرك أو الخرائط مع كل تعديل للشكل.

الإصدار الظاهر **3.0**؛ رقم البناء **3.0.2**. يتضمن الشعار باسم محمود نور الدين الحداد وبمساعدة إيفا، ورسالة سلامة عربية وإنجليزية، ووضع خريطة ثنائي الأبعاد أخف. تحسّن السرعة لم يُقَس بعد على الجهاز.

**التوافق المثبت:** ملف جهاز SiRF Windows CE بشاشة 480×272، ذاكرة TFAT/FAT32 بحجم 3,789,553,664 بايت، مع نسخة الملاحة المدعومة الموجودة مسبقاً. لا يُفترض توافق موديلات أخرى تلقائياً. أدوات البائع والكود تبقى في المستودع الخاص.

## English

The customer edition downloads selected compatible offline maps and installs signed Atlas navigation customization updates. It preserves personal settings and keeps verified backups of replaced files. The first stable lightweight profile changes only the existing 3D-view preference to 2D; other user settings are retained.

This is a navigator software customization, not a replacement Windows CE firmware. Public packages contain Atlas appearance files and patches for an existing supported installation, not the original navigation engine, firmware or map library. MapFactor Navigator and OpenStreetMap notices remain intact.

USB cable data-disconnect experiments are excluded; that feature did not work reliably on the tested device. Live map catalogue availability, satellite reception, driving/camera coverage and hardware RAM are not certified by these release checks.
